# CS Lab — Interactive Learning Website

A responsive, frontend-only React website that turns three introductory Computer Science topics into interactive playgrounds.

## Included modules

1. **Formal Language and Automata Theory — DFA Simulator**
   - Enter a binary string.
   - Run it through a deterministic finite automaton.
   - See the transition trace and accepted/rejected result.
   - The sample DFA accepts strings with an even number of `1`s.

2. **Computer Organization and Architecture — Number Systems**
   - Convert non-negative values between binary, octal, decimal, and hexadecimal.
   - View binary place-value breakdown.
   - Copy converted values.

3. **Design and Analysis of Algorithms — BFS Graph Explorer**
   - Choose a starting node.
   - Step through Breadth-First Search or run the traversal.
   - See visited nodes and traversal order.

4. **Quick knowledge check**
   - Three multiple-choice questions with score feedback.

## Tech stack

- React
- Vite
- Vanilla CSS
- Lucide React icons

No backend or database is required.
